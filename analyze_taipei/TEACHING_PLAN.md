# 《透析臺北——文本比較》素養導向教學活動設計方案

## 一、 活動主題與教學核心
- **課程主題**：透析臺北——文本多維度比較與觀點思辨
- **設計理念**：臺北不只有一種面貌。本課程引導學生跳脫單一視角，透過閱讀四篇不同時代、身份與觀察角度的經典與當代文本，學習「提煉關鍵要點」、「建構比較圖表」、「批判思辨作者觀點」，並最終「建構屬於自己的臺北城市論述」。
- **核心素養對應**：
  - 國-J-B1 運用語言文字、圖表與數位科技，理解各類文本並表達多元觀點。
  - 國-J-C2 具備探究城市地景與社會議題的思辨能力，能同理不同族群之生命經驗。

---

## 二、 學習目標
1. **要點統整與比較**：能辨識並摘要四類文本中關於「空間焦點、生活步調、人際關係、情感態度」等核心要點，並列出異同。
2. **圖表視覺化統整**：能運用雷達圖與矩陣對照表，將多文本的抽象感受轉換為具象化之向度評比與關聯圖。
3. **觀點思辨與立場表態**：能針對作者提出的核心論點進行批判性審視，清楚說出「認同」或「不認同」的依據與個人生活經驗。
4. **個人論述建構**：能綜合文本比較心得，寫出一段兼具客觀觀察與主觀省思的「我的臺北微文本」。

## 四、 90分鐘教學流程規劃表

| 階段與時間 | 教學活動步驟 | 學習者任務 | 數位工具/網頁支援 |
| :--- | :--- | :--- | :--- |
| **【引起動機】**<br>00~10 min | **1. 臺北第一印象字雲**<br>提問：「如果用三個詞形容臺北，你會選什麼？」邀請學生線上輸入或口語分享，歸納班級普遍印象（擁擠、繁華、快節奏？）。 | 分享個人對臺北的直觀印象與生活經驗。 | 網頁【引言導讀】與互動詞彙探索。 |
| **【發展活動一】**<br>10~30 min | **2. 文本深讀・要點解碼**<br>學生分組或個人閱讀四大文本精選片段。依據五大關鍵要點提取標籤：<br>①觀察視角 ②空間焦點 ③生活節奏 ④人際溫度 ⑤情感色調。 | 閱讀並點擊網頁「要點揭曉」，標記關鍵文句並檢核自己的歸納。 | 網頁【單元一：四大文本精讀展覽室】（點擊揭示核心句與視角標籤）。 |
| **【發展活動二】**<br>30~55 min | **3. 圖表統整・視覺化對照**<br>展示「多維度城市風貌雷達圖」及「文本綜合比較矩陣表」。<br>引導分析：為什麼舒國治的「悠活度」最高，而青年篇的「壓力感」破表？ | 觀察雷達圖五邊形分佈，比較四篇文本在指標上的極端差異與交集。 | 網頁【單元二：動態圖表統整中心】（可切換雷達圖、柱狀圖與多向度矩陣）。 |
| **【發展活動三】**<br>55~75 min | **4. 觀點交鋒・思辨天平**<br>針對四大文本的核心爭鳴論點進行思辨表態：<br>• 舒國治說的慢活是真實臺北還是文人濾鏡？<br>• 都市的冷漠究竟是「隱私自由」還是「人情凋零」？<br>• 臺北真的「親近自然」嗎？你感受到了嗎？<br>• 北漂青年的焦慮是否具有普遍性？ | 在線上天平選擇「認同／部分認同／不認同」，並撰寫100字理由。 | 網頁【單元三：觀點思辨天平與論壇】（即時投票統計與觀點闡述）。 |
| **【總結與輸出】**<br>75~90 min | **5. 我的臺北微書寫與成果產出**<br>結合統整經驗，寫出一段「我眼中的臺北」，並產出個人專屬學習報告單。 | 統整所學，輸入個人視角，一鍵匯出學習成果報告單。 | 網頁【單元四：個人臺北微觀點生成器】與一鍵列印/下載功能。 |

## 五、 配套網頁系統功能說明
1. **自適應互動介面**：支援手機、平板、筆電與教室大螢幕投影。
2. **Chart.js 動態雷達圖**：提供視覺化五向度分析，可自由開關文本圖層進行疊圖比較。
3. **文本折疊與語音朗讀**：支援 Web Speech API 語音發音朗讀，輔助聽覺與沉浸式學習。
4. **思辨投票與即時統計**：引導學生表態，強化自主思考與批判閱讀能力。
5. **一鍵成果列印／匯出**：學生填寫完個人見解後，可直接匯出標準格式的學習成果單供教師批閱評量。
