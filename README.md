## 課程核心單元架構

1. **單元 1：歌SONG臺北** (`gesong_taipei/index.html`)  
   - 音樂地誌與城市情感探究，結合黑膠唱盤／MV雙模播放器、歌詞挖洞翻牌、田字格注音查一查與深層探究。
2. **單元 2：故事．臺北．人** (`yes_composition/g8a-story-taipei-expansion.html`)  
   - 人物觀察與五感生動擴寫指南，包含 Before/After 雙欄對照範例、AI 寫作教練引導。
3. **單元 3：透析臺北――文本比較** (`analyze_taipei/index.html`)  
   - 跨文本矩陣、五維度雷達圖、語音朗讀與批判性思辨教學平台。
4. **單元 4：臺北文青打卡趣** (`wenchin_taipei/index.html`)  
   - 穿梭十二行政區文化地景圖鑑、名家文學地誌賞析、文青打卡大挑戰互動任務與素養闖關測驗。
5. **單元 5：網羅臺北** (`wangluo_taipei/index.html`)  
   - 深入各類出處數位文本庫，依據「權威和品質評鑑」五大指標檢視數位資訊與視角差異。
